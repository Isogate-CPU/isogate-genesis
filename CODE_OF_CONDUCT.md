# Code of Conduct

## Our standard

We aim to keep technical discussion respectful, inclusive, and focused on
improving the work. Participants should be constructive, assume good intent,
explain disagreements clearly, and welcome different experiences.

Harassment, discrimination, threats, intimidation, doxxing, unwanted sexual
attention, and other abusive or disruptive behavior are not acceptable in
project spaces.

## Enforcement

Maintainers may remove content, pause a discussion, or restrict participation
when behavior violates this standard. To report a concern privately, contact
[support@isogate.tech](mailto:support@isogate.tech) with links or other context
where available. Reports will be handled as confidentially as practical.

This code applies to project issues, pull requests, reviews, and other spaces
used for project collaboration.
